# Airhockey

Ein schnelles Airhockey-Spiel für das iPad, vollständig in einer einzigen `index.html` umgesetzt. Es funktioniert offline und benötigt weder Konto noch Server oder externe Bibliotheken.

## Funktionen

- Einzelspieler mit den Schwierigkeitsgraden Einfach, Normal und Schwer
- Zwei Spieler auf demselben Gerät mit Multi-Touch-Steuerung
- Canvas-Physik, Tore, Punktestand und Spielende bei 7 Punkten
- Pause, Neustart und Moduswechsel
- Lokale Bestenliste mit `localStorage`
- Responsives Querformat-Layout für unterschiedliche iPad-Größen

## Spielen

Die veröffentlichte Version läuft direkt über GitHub Pages. Alternativ kann `index.html` lokal in einem modernen Browser geöffnet werden.

Den Schläger mit dem Finger oder Mauszeiger ziehen. Jeder Schläger bleibt automatisch in seiner eigenen Spielfeldhälfte.

## Technik

HTML, CSS und JavaScript befinden sich gemeinsam in `index.html`. Es werden keine externen Bibliotheken, Bilder oder Netzwerkdienste verwendet.
